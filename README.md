# Floating Point Lab

Step-by-step practice converting between binary floating point and denary, using two's complement mantissa and exponent (OCR A Level Computer Science, H446).

## Features

### Binary → Denary
- Work out the exponent, float the point, add the column headings, then work out the value
- Each stage is checked before moving on, with hints and a reveal button
- The binary point is animated as it floats

### Denary → Binary
- Write the number in fixed-point binary, normalise it, then fill in the register

### Options
- Formats from 4-bit mantissa/4-bit exponent up to 8-bit mantissa/4-bit exponent, or any mix
- Normalised only, negative mantissas and negative exponents can be switched on or off
- **Set your own** to enter a number from a worksheet or past paper
- Score for right first time, plus a streak

## How to Use

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari). Nothing to install, no login.
2. Choose **Binary → Denary** or **Denary → Binary**
3. Pick a format, or leave it on **Any mix**
4. Work through each numbered stage, pressing **Check** as you go

## Use Cases

- Teaching the method one stage at a time
- Independent practice with instant feedback
- Checking answers to past paper questions

## Tech

- A single HTML file: HTML, CSS and plain JavaScript
- No libraries, no build step, no backend
- Google Fonts for the typefaces (falls back to system fonts offline)
- Light and dark themes
